01 · El conceptoPrecio proporcional, no por bloques

La calculadora responde a una sola pregunta: ¿cuánto cuesta enviar un paquete que pesa X gramos? Toma el peso real —en kilos y gramos— y devuelve un costo estimado en dólares.

La idea central es que el precio no se cobra por rangos ni por bloques redondeados. Muchos couriers cobran «hasta 1 kg → tal precio», de modo que 510 g y 990 g pagan lo mismo. Acá no: el precio sube de forma proporcional (lineal) según el peso exacto. Cada gramo adicional tiene un costo, y ese costo se calcula entre puntos de referencia.

La clave Los pesos de la tabla (0,5 kg · 1 kg · 1,5 kg · 2 kg) son puntos de referencia, no escalones. Entre un punto y el siguiente, el precio se interpola de forma lineal: sube parejo, gramo a gramo, sin saltar al tramo superior.

LOS CUATRO PUNTOS DE REFERENCIA

Todo el cálculo se apoya en cuatro precios de anclaje. Son la única «fuente de verdad» del tarifario:

Punto de referenciaPesoPrecio ancla
Tarifa mínimahasta 0,5 kg (500 g)USD 12,50
Segundo ancla1 kg (1 000 g)USD 17,50
Tercer ancla1,5 kg (1 500 g)USD 26,25
Cuarto ancla2 kg (2 000 g)USD 35,00
Sobre los 2 kg: a partir del cuarto ancla el precio deja de interpolarse y pasa a un tramo abierto: se toma la base de USD 35,00 y se suma USD 1,85 por cada 100 g adicionales (equivalente a USD 0,0185 por gramo).

02 · La mecánicaTres zonas de cálculo

Según dónde caiga el peso del paquete, la calculadora aplica una de tres reglas. Estas tres zonas cubren cualquier peso posible:

1
0 – 500 g
Tarifa mínima

Todo paquete hasta medio kilo paga el precio piso: USD 12,50. Es un valor fijo, no importa si pesa 50 g o 500 g.

2
500 g – 2 kg
Interpolación lineal

Entre dos anclas consecutivas el precio sube parejo según los gramos que superen el ancla anterior.

3
más de 2 kg
Base + adicional

Base fija de USD 35,00 más USD 1,85 por cada 100 g por encima de los 2 kg.

ZONA 2 · LA FÓRMULA DE INTERPOLACIÓN

Es el corazón del modelo. Para un peso entre el ancla anterior y la actual, el precio se calcula así:

precio = precioant + (gramos − pesoant) × pendiente donde   pendiente = (precioact − precioant) ÷ (pesoact − pesoant)

La pendiente es el costo por gramo del tramo. Como cada tramo mide 500 g, cambia según cuánto sube el precio en esos 500 g:

TramoSubeEnCosto por gramoPor 100 g

1 kg → 1,5 kgUSD 8,75500 gUSD 0,0175USD 1,75
1,5 kg → 2 kgUSD 8,75500 gUSD 0,0175USD 1,75
más de 2 kg——USD 0,0185USD 1,85

Cómo leerla: un paquete de 650 g cae en el primer tramo (0,01/g) → 12,50 + 150 × 0,01 = USD 14,00.

03 · VisualizaciónLa curva de precios

El gráfico muestra el costo (eje vertical, USD) contra el peso del paquete (eje horizontal, en kg). Fijate cómo la línea es un tramo plano al inicio, luego sube en segmentos rectos que cambian de inclinación en cada ancla, y finalmente continúa recta más allá de los 2 kg.

QUÉ REVELA LA CURVA

El tramo plano inicial es la tarifa mínima. A partir de 500 g la línea se «quiebra» y sube: primero suave (1,00 c/100 g), luego más empinada a partir de 1 kg (1,75 c/100 g).

MÁS ALLÁ DE 2 KG

La pendiente se vuelve apenas mayor (1,85 c/100 g) y la recta continúa sin techo. No hay saltos: el precio siempre es continuo, sin escalones bruscos.

05 · Detalles finosRedondeo y código real

REDONDEO A DOS DECIMALES

Todo resultado se redondea a dos decimales (centavos). Para evitar los típicos errores de punto flotante —donde 35,0925 podría representarse como 35,09249999…— se suma un epsilon mínimo antes de redondear. Así el redondeo es estable y predecible:

redondear(n) = Math.round((n + 0,000000001) × 100) ÷ 100
Por eso 2 005 g da exactamente USD 35,09: el valor real 35,0925 se redondea hacia abajo a 35,09 de forma consistente.

EL CÓDIGO QUE LO IMPLEMENTA

La función real, única fuente de verdad (src/lib/tarifas.ts):

// Costo de envío en USD a partir del peso EXACTO en gramos.
export function calcularTarifa(gramos) {
  if (!Number.isFinite(gramos) || gramos <= 0) return 0;

  const primero = TARIFAS[0];
  // Zona 1 — hasta el primer ancla: tarifa mínima.
  if (gramos <= primero.hasta) return redondear2(primero.precio);

  // Zona 2 — interpolación lineal entre dos anclas.
  for (let i = 1; i < TARIFAS.length; i++) {
    const ant = TARIFAS[i - 1], act = TARIFAS[i];
    if (gramos <= act.hasta) {
      const pendiente = (act.precio - ant.precio) / (act.hasta - ant.hasta);
      return redondear2(ant.precio + (gramos - ant.hasta) * pendiente);
    }
  }

  // Zona 3 — más de 2 kg: base + USD 1,85 cada 100 g.
  const ultimo = TARIFAS[TARIFAS.length - 1];
  return redondear2(ultimo.precio + (gramos - ultimo.hasta) * (1.85 / 100));
}
En resumen Un solo número de entrada (gramos), tres zonas de cálculo, cuatro precios ancla y un redondeo estable. El resultado es un precio continuo, justo y proporcional al peso real de cada paquete — sin escalones ni sorpresas.
